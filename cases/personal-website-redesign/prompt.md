# Case 3: Personal Website Redesign

## Instructions for the candidate model

Redesign the personal website at https://samstarkman.com.

### What to do

1. **Inspect the live site** at https://samstarkman.com. Explore the visible layout, navigation, routes, and content. Pay attention to the `/writing` section which features long-form posts.

2. **Identify improvements** using your own judgment. Look at:
   - Visual design (typography, spacing, color, hierarchy)
   - Information architecture and navigation
   - Content presentation and readability
   - Overall aesthetic coherence

3. **Build a standalone redesign** as a single HTML file with embedded CSS and minimal JavaScript. The redesign should:
   - Be runnable locally by opening the HTML file in a browser
   - Reflect an improved version of the site's design and layout
   - Preserve the site's identity and content structure
   - Be self-contained (no external dependencies that require a server)

### Constraints

- You do NOT have access to the private repository. Work only from what you can see on the live public site.
- Create one complete `index.html` file with all styles and scripts embedded.
- The file should be production-quality HTML/CSS.

### Output

Provide the complete `index.html` file. Include brief notes explaining your key design decisions and what you improved.
